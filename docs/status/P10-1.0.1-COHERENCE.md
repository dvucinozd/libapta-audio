# P10 — APTA 1.0.1 coherence release

## Objective

Publish a maintenance release that makes every current public document and
package manifest agree with the stable APTA 1.0 contract while preserving the
immutable `v1.0.0` release and all technical compatibility boundaries.

## Included

- final status labels for the normative component documents;
- APTA 1.0 errata 1 and refreshed normative Git-blob hashes;
- stable API, packaging, governance, contribution and file-format guidance;
- package `1.0.1`, public API `1.0.0`, conformance-suite `1.0.1` and ESP-IDF component `1.0.1`
  release identity;
- version-derived stable release automation and maintenance-release verifier;
- deterministic Linux and Windows package, checksum and conformance evidence.

## Explicitly unchanged

- exported symbols and public structure layouts;
- `SOVERSION 1`;
- `.apta` container version 1, section layouts and canonical fixture bytes;
- conformance profile definitions;
- parser/writer and production DSP behavior;
- historical S0–S9 and release-candidate evidence;
- immutable `v1.0.0` tag and release assets.

## Exit gate

P10 completes when the maintenance verifier, legal review, normal CI,
reference-fixture, ESP-IDF and deterministic release-package workflows pass and
the merged commit is published as `v1.0.1`.
