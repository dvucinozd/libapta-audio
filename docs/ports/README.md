# Platform porting documentation

The current platform component is ESP-IDF:

- [`../../ports/espidf/README.md`](../../ports/espidf/README.md) — canonical
  component integration guide.
- [`esp-idf/README.md`](esp-idf/README.md) — documentation-tree pointer.

POSIX support currently consists of the optional desktop adapters documented in
[`../reference/APTA-DESKTOP-TOOLS-0.1.md`](../reference/APTA-DESKTOP-TOOLS-0.1.md).
Windows, Zephyr and bare-metal integrations remain candidates for Stage S8;
this directory does not claim that those ports exist.
