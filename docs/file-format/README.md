# `.apta` file-format documentation

The stable container-version-1 requirements are maintained in
[`../../specification/file-format.md`](../../specification/file-format.md), with
section registration in
[`../../specification/container-v1-registry.md`](../../specification/container-v1-registry.md)
and global-grid/revision rules in
[`../../specification/global-grid-container.md`](../../specification/global-grid-container.md).

The APTA 1.1 optional `MKEY`, `MTRD` and `CONF` payloads are specified in
[`../../specification/APTA-1.1-DJ-SECTIONS.md`](../../specification/APTA-1.1-DJ-SECTIONS.md)
without changing the frozen APTA 1.0 normative manifest.

Implementation records in this directory:

- [`APTA-WOVR-READER-WRITER-STATUS-0.1.md`](APTA-WOVR-READER-WRITER-STATUS-0.1.md)
  — historical WOVR reader/writer baseline and parser-limit clarification;
- [`APTA-META-STATUS-0.1.md`](APTA-META-STATUS-0.1.md) — historical META
  ownership, limits, CBOR encoding and verification evidence.

The `0.1` suffix identifies historical implementation records; it does not
change the stable APTA 1.0 or container-version-1 authority. Current release and
conformance status is recorded in
[`../status/APTA-ROADMAP-STATUS.md`](../status/APTA-ROADMAP-STATUS.md) and the
public suite under [`../../conformance/`](../../conformance/).
